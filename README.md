# StandBy για Android

Οθόνη τύπου iPhone StandBy: όταν το κινητό φορτίζει δείχνει ρολόι, ημερομηνία, καιρό, μπαταρία και τα επόμενα ραντεβού. Η οθόνη είναι οριζόντια.

## Build
1. Δημιούργησε νέο repo στο GitHub (π.χ. `standby`) και ανέβασε όλα τα αρχεία, μαζί με τον φάκελο `.github`.
2. Πήγαινε στο Actions → «Build APK» και περίμενε 3-4 λεπτά.
3. Κατέβασε το `standby-apk` από τα Artifacts, αποσυμπίεσε και εγκατέστησε το `app-debug.apk`.

## Ρύθμιση στο κινητό
1. Άνοιξε την εφαρμογή StandBy και δώσε τις άδειες.
2. Πάτα «Ενεργοποίηση» και διάλεξε **StandBy** ως προφύλαξη οθόνης.
3. Στην ίδια οθόνη όρισε «Πότε να ξεκινά» → **Κατά τη φόρτιση**.

## Σημειώσεις
- Ο καιρός έρχεται από το Open-Meteo, χωρίς κλειδί API. Χωρίς άδεια τοποθεσίας δείχνει Αθήνα.
- Από τις 23:00 ως τις 07:00 τα γράμματα γίνονται κόκκινα και χαμηλωμένα. Αυτό απενεργοποιείται από τις ρυθμίσεις.
- Το περιεχόμενο μετακινείται λίγο κάθε λεπτό, για να μη μαρκάρει η οθόνη.
- Στα Samsung η επιλογή βρίσκεται στις Ρυθμίσεις → Οθόνη → Προφύλαξη οθόνης.
